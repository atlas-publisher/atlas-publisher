Privacy Policy — Atlas Publisher

Effective date: October 18, 2026
Operator: Atlas Publisher (a publishing tool operated for the @atlasshortstv and The Final Shift creator channels)
Contact: ayazdurkhani7@gmail.com

1. What this tool is

Atlas Publisher is a web-based publishing tool that uploads original short videos created by our team to TikTok accounts we operate, using TikTok's official Content Posting API. It is not a consumer app and does not serve the general public; it is used only by our own channel operators.

2. Data we collect

When a creator connects their TikTok account, TikTok's OAuth flow gives us:

  • TikTok open_id — TikTok's identifier for the connected account (used to address API calls to the right account).
  • Access token and refresh token — credentials that let our server call TikTok's API on the connected account's behalf for the scopes the creator approved (user.info.basic, video.upload, video.publish).
  • Basic profile info (user.info.basic scope only): display name and avatar, shown in our tool so the operator can confirm the correct account is connected before publishing.

When a video is published, we log: the TikTok publish_id, the post status returned by TikTok, the caption used, and timestamps. This log exists only for troubleshooting failed uploads.

We do not collect, read, or store: follower lists, private messages, comments, analytics, device data, location data, or any data about TikTok users other than the connected creator accounts described above.

3. How TikTok data is used

  • Tokens are used solely to upload videos and check publish status on the connected creator's own TikTok account, at the creator's direction, on the scopes the creator approved.
  • Profile info is displayed in our tool's interface only, to confirm account identity.
  • Publish logs are used only to diagnose failed or stuck uploads.

4. How TikTok data is stored and protected

  • Tokens are stored server-side in an encrypted credential store. They are never embedded in client-side code, never logged, and never included in URLs.
  • Access tokens expire every 24 hours per TikTok's design; our server refreshes them using the refresh token over an encrypted connection.
  • Server access is restricted to the channel operators. No third party has access to the tokens.

5. Data sharing

We do not sell, rent, or share any TikTok user data with any third party, advertiser, or data broker. The only external service that receives data is TikTok itself, via its official API, as required to perform the upload the creator requested.

6. Data retention and deletion

  • Tokens are kept only while the creator's account stays connected. Disconnecting the account in our tool deletes the stored tokens immediately.
  • Publish logs are kept for 90 days for troubleshooting, then deleted.
  • A creator may request deletion of all data we hold about their account at any time by contacting us at the email above; we will confirm deletion within 7 days.

7. Children's data

This tool is operated by and for adult channel operators. It is not directed at children, and we do not knowingly collect data from anyone under 18.

8. Changes to this policy

If this policy changes, the updated version will be posted at this same URL with a new effective date. Material changes will be communicated to connected creators before they take effect.
